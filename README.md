# MIND

MIND is a responsive landing page created for a company focused on marketing, design and custom AI solutions.

The project was designed from scratch in Figma and developed with React, Vite and Framer Motion. The website presents the company's services, value proposition and contact information through a clean and modern interface.

## Technologies

- React
- Vite
- JavaScript
- CSS
- Framer Motion

## Requirements

Before running the project, make sure you have Node.js and npm installed.

Recommended version:

```bash
Node.js 18 or newer
```

## Installation

Clone the repository:

```bash
git clone <repository-url>
```

Open the project folder:

```bash
cd <project-folder>
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The local address will be displayed in the terminal.

## Production build

Create the optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
